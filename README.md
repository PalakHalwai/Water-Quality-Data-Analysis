# Water Quality Data Analysis for Community Awareness (CEP)

This repository contains the Data Science Community Engagement Project (CEP) analyzing community water sources, filtration practices, and reported health complaints.

## Project Structure
- `water_community_data.csv`: Community survey dataset (150 responses).
- `Analysis.py`: Script for statistical frequency distributions and core cross-tabulation heatmaps.
- `Problem_Statements_Charts.py`: Script generating visualizations for community problem statements 1, 2, 3, and 5.
- `Generate_PS4.py`: Script generating visualization for problem statement 4 (Age vs. Purification Method).
- `*.png`: Generated figures and heatmap charts for project report.

## Tech Stack
- Python (Pandas, Seaborn, Matplotlib, NumPy)
